Da lógica combinacional à memória

Aula prática via simulador sobre estado sequencial, SR latch, D latch, D flip-flop, registrador e Program Counter.

Pergunta PBL: como um circuito consegue lembrar um valor se a lógica combinacional depende apenas das entradas atuais?
0 de 6 etapas exploradas

1. O que muda quando o circuito ganha memória?

Lógica combinacional

A saída depende somente das entradas atuais. Se as entradas forem iguais, a saída será a mesma.

Y(t) = f(A(t), B(t))

Exemplos: AND, OR, XOR, MUX e decoder.

Lógica sequencial

A saída depende das entradas atuais e do estado armazenado anteriormente.

Q(t+1) = f(entrada(t), Q(t))

Estado é a informação necessária para explicar o comportamento futuro do circuito.

Ideia central: circuitos sequenciais conseguem lembrar valores entre ciclos.

2. SR Latch — Set e Reset

O SR latch armazena 1 bit. As entradas S e R determinam a ação sobre Q.

Desafio: faça SET, depois HOLD, depois RESET e por último experimente S = R = 1. Explique o problema do estado inválido.

3. D Latch — sensível ao nível do clock

CLK = 1: o latch fica transparente e Q acompanha D.

CLK = 0: o latch fica opaco e Q mantém o valor anterior.

A entrada D elimina a combinação inválida do SR latch.
Q armazenado0
CLK = 0: o latch está opaco.
Desafio: deixe CLK = 1 e altere D algumas vezes. Depois coloque CLK = 0 e altere D novamente. Compare o comportamento de Q.

4. D Flip-Flop — sensível à borda

O D flip-flop captura D somente na borda de subida do clock (0 → 1).

CLK ↑ → Q ← D

Fora desse evento, Q mantém o estado anterior.

5. Registrador de 4 bits

Um registrador agrupa vários elementos de estado para guardar uma palavra. Aqui usamos 4 bits para visualização; no projeto, os registradores serão de 32 bits.

LOAD = 1: no pulso, o novo valor é armazenado.

LOAD = 0: no pulso, o valor anterior é mantido.

Entrada binária1011
Q armazenado0000
Pronto para armazenar.
Desafio: armazene 1011. Depois coloque LOAD = 0, altere a entrada para 0011 e gere outro pulso. Q deve continuar 1011.

6. Program Counter como estado sequencial

O PC guarda o endereço da próxima instrução. Ele precisa manter estado entre ciclos.

  • manter o valor;
  • incrementar;
  • carregar outro endereço em salto/desvio;
  • reiniciar com reset.

A simulação usa 4 bits para tornar o comportamento visível. O projeto usará 32 bits.

PC atual0000decimal: 0
Estado inicial.
Desafio final: incremente duas vezes, carregue 9, incremente uma vez e execute reset. Explique por que o PC precisa guardar estado.

  5. experimento do registrador com LOAD = 1 e LOAD = 0;

  7. conclusão explicando como flip-flops permitem construir registradores e PC.
