# Como contribuir

1. Crie uma branch curta e descritiva.
2. Mantenha instruções em português brasileiro, com frases curtas.
3. Inclua testes para mudanças nas regras do simulador.
4. Execute `pnpm test`, `pnpm lint` e `pnpm build` antes de enviar a contribuição.
5. Evite dependências externas em tempo de execução e preserve a acessibilidade.
